# To-Do List Application

## Description
A simple GUI-based To-Do List application developed using Python and Tkinter.

## Features
- Add tasks
- Delete tasks
- Clear all tasks
- User-friendly interface

## Technologies Used
- Python
- Tkinter

## Installation

1. Clone repository

git clone https://github.com/Rishitha-Angel-Kancharla/todo-list-app.git

2. Navigate to folder

cd todo-list-app

3. Run project

python main.py
